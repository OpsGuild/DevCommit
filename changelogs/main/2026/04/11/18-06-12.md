# Changelog

## [Unreleased]

### Added
- New `CHANGELOG_MODE` configuration option to control changelog storage behavior
- Support for two changelog modes:
  - `timestamped` (default): Creates new timestamped files per run in `changelogs/<branch>/<year>/<month>/<day>/<time>.md`
  - `branch`: Maintains one changelog file per branch at `changelogs/<branch>.md` with prepended entries

### Changed
- Improved changelog content normalization to automatically remove:
  - Empty sections and placeholders
  - Unused `## [Unreleased]` headings when empty
  - Redundant formatting and whitespace
- Updated documentation to reflect new changelog modes and behavior
- Example configuration files now include `CHANGELOG_MODE` setting

### Fixed
- Changelog generation now properly handles AI-generated content with:
  - Better detection of placeholder text
  - More reliable section parsing
  - Cleaner output formatting
- Empty changelog sections are automatically removed to keep files clean
